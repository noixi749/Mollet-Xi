記録（点火マップを取る）

走りながら、低い回転から高い回転まで何回か回すと、回転ごとの点火時期がたまっていきます。リミッターも拾います。

  3. 下の「今の値」が落ち着いている時に 「この値で基準を決める」

基準のしくみ

データ盗む君は、パルサーの信号から火花までの時間を測って、「1回転のうちどこで火花が飛んだか（位相）」を出します。パルサーが上死点の何°前にあるかは車ごとに違うので、アイドリングの1点だけタイミングライトで角度を教えると、あとは全部の回転で角度に直せます。

基準は、あとから入れ直しても大丈夫です。記録したマップは、いつでも今の基準で計算し直します。

使い方

1. 車体につなぐ（3本だけ）

  1. パルサーの線（今の CDI へ行っている線）に、データ盗む君の「パルサー」の線を並べてつなぐ（タップ）。CDI の線は切らない。カプラの後ろから細い針を差してワニ口でつまむか、ギボシの Y 分岐で
  2. 車体アースの線を、フレームのボルトかアースの線にワニ口でつなぐ（パルサーが2本線の時は、パルサーのもう1本へ）
  3. 細い線をプラグコードに 3〜5回巻いて、両端を「巻線①②」へ
  4. ESP32 の USB にモバイルバッテリー

「パルサー /秒」と「火花 /秒」が、どちらも回転÷60 くらいになれば OK。火花が0なら巻線①②を入れ替えます。

2. 基準合わせ（アイドリングで1回）

「基準」のタブで、タコメーターの回転とタイミングライトの角度を入れて決めます。

3. 走って記録

「記録を始める」を押して走ります。低い回転から上まで、何回か回してください。1000rpm ごとに数十点たまれば、その回転は信用できます。グラフの点が縦に広がる所は、CDI が回転以外（加速中など）でも角度を変えている所です。

4. 使う

「マップ」のタブで見られます。盗んだマップは、同じスマホの Mollet Xi と 耐久がんこちゃん の「CDI → アプリのプリセット → データ盗む君から」にそのまま出ます（ブラウザ版どうしも同じ）。別のスマホへは「SHIRATAKI（Mollet Xi）に送る」のリンクで。CSV で保存もできます。

SHIRATAKI の点火は 0〜25° の範囲なので、それを超える所は 0° か 25° にそろえて送ります。
